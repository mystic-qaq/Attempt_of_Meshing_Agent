# API 预算与实验资源

API 费用、原生网格计算、独立测量和完整墙钟时间分别记录。模型与程序反馈的尝试额度相同，并不意味着实际计算量相同。

## 源几何账本

DrivAer 研究设置每个原始源几何 $0.50 的 API 上限，同源重试、不同路线和版本共用账本。派生副本不构成新的独立案例，也不获得新的预算。

|源案例|本轮 API 保守上界|案例上限|
|---|---:|---:|
|DrivAer 1|$0.441173|$0.50|
|DrivAer 318|$0.470756|$0.50|
|DrivAer 410|$0.366667|$0.50|

这些数字是研究预算的保守上界，含未取得完整回执的预留额，不是供应商逐笔账单或项目全部历史成本。被中断的 Pro 请求保留已知费用与未知预留，并排除于 Flash 性能结果。最终配对阶段新增 Flash 上界为 $0.071285。

## 预留与结算

请求前按输入和输出上界预留；取得 usage 后计算已知费用。缓存信息已知时单独处理；无法确认的请求保留其预留，不从账本自动释放。账本记录用于约束后续调用，后验价格核算不回写历史决策。

早期实验另保留当时记录与后验时段核算：[原费用记录](../results/drivaer_v9_20261012/usage.json)、[核算记录](../results/drivaer_v9_20261012/usage_reconciled.json)。它们与当前研究的源组账本分别解读。

原生资源与完整结果见[实验索引](EXPERIMENTS.md)。原始网格留在独立存储中；费用文本和参数记录的发布版本去除了账户身份与环境路径。
