# 面向 DrivAer 汽车数据的 Meshing Agent

**2026-10-13：研究结束，未证明明显优于程序化方案。** 最后一轮 `deepseek-flash` 与程序反馈各三次完整生成，没有合格研究候选。以下保留已实现的接口、实验条件与未验证的研究设计。见[最终结论](../results/drivaer_focus_20261012/FINAL_CONCLUSION.zh-CN.md)。

0.10.14 的目标是研究级的可验证网格优化：在固定输入几何、流向、首层物理高度、OpenFOAM 版本和预算下，检验开源模型决策是否优于程序化方案。实验基座为 `deepseek-flash`。当前工况仍是自由空气单相外流，不宣称道路/旋转车轮或生产 RANS 精度。

旧 0.9.1 及此前数据均是历史证据，不能用新代码回写。新协议的程序化直出为相同初始化的 snap + layer 两个阶段；snap 失败时明确记为基线失败，模型修复后的首张层网格不会被冒充程序化基线。

## 主要实现

- 独立 snap 验收；合格中间网格通过五个 polyMesh 核心文件 hash 注册。加层只在独立文件副本上执行，禁止链接；源文件前后 hash 必须相同。
- 一旦 snap 控制、体加密、生成质量或几何变更，原锚点不能复用，必须重新执行并验收 snap。
- 保留可行网格的覆盖—单元数 Pareto 集。无效高覆盖网格不得替换候选；负体积等失败试验从合格阶段重新出发。
- DrivAer 对话允许多轮基于结果继续查询。传给模型的视图去除重复模板与 region 理由，完整原始证据仍在磁盘；数值不舍入，测量回执与空间库存进入纠错上下文。
- `cluster_refine` 使用实测问题簇 ID，由程序按记录生成坐标盒子。预演拒绝无变化、对 snap 失败只改层参数，以及已经测过的重复阶段；原始提案与解析后的动作分别记录。
- 0.10.3 的研究协议采用两轮查询、低思考预算、程序认证后单次提交；保留原生质量/几何/资源验证。旧的额外 LLM 科学复核仍为通用接口默认选项，可通过 `--review-policy llm` 使用。省略第二次付费复核不表示模型的解释被证实。
- 主模型为 `deepseek-flash`，官方在 2026-10-12 将其映射为 DeepSeek-V4.1-Flash。开放权重地址 https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash 。API 返回 model 字段与每次用量单独保存，不能声称 API 与某个下载 checkpoint 数值完全一致。
- 每个源几何在本轮研究中 API 费用最多 $0.50，重试与不同 arm 共用；旧实验费用保留并另列，新 protocol 的授权范围明确记录。
- 独立 CGAL 源检查保留 OpenFOAM 的原始报告，并验证闭合、朝向、单连通体、退化面和自交；两者不一致时明确标记。它不替代最终体网格质量或边界几何检查。
- 完整流水线诊断分支从原始参数重新生成，允许测量表面处理与层构造的联合作用；没有把失败中间网格注册成合格锚点。最终可行候选仍需经过全部网格/保真门槛。
- 原始层数和总厚度的面积指标进入诊断与 Pareto 比较，防止只缩短目标层数取得好看的 C5。跨案例记忆使用无量纲描述、不可变测量和不同原始源组；不复制坐标、簇 ID，不自动提升失败经验为正向规则。
- 新增同源、相同吸附参数的加层前后质量对照；它提供阶段作用的证据，不能证明唯一因果，也不授权复用失败网格。大区域库存采用保留精确数值的列式视图，上次方案采用相对当前方案的差异，原始 JSON 与计算回执不改写。
- 0.10.8 的开发分支可冻结同案例纯程序完整基线的单元数，以两倍余量校准旧的加法成本预估。旧预估重复计算重叠区域、已细化区域及固体内部；校准是规划启发式，不是数学上界。原生最大单元数、运行期监控、最终实测预算、质量和保真门槛不变。追加开发计算与同预算比较分开报告。
- 被用户中断的 Pro 试验只作为取消记录保留；已知费用与未取得回执的保留额继续计入原始案例预算，不进入 Flash 的收益证据。
- 同源、同可执行参数的未提交 Flash 决策可以复用已有的可见工具回执；没有完整回执的请求明确标作未测量，最终方案仍必须重新预演。提交阶段保留精确全局参数、实测目标及回执，省略重复的未变区域库存；在预算许可范围内缩短无隐藏推理的最终 JSON 输出上限。原始证据、费用和失败决策均保留，不重置账本。
- 校准分支同时冻结更强的程序对照：全局细化一次，以及配合固定吸附/加层设置的两种策略。模型与该程序路线使用相同初始参数、校准、单元上限与新试验次数；不能把仅模型可用的新资源策略冒充公平对照。

## 比较与通过条件

同时报告程序化首次生成、同等阶段/时间预算的固定程序反馈，以及 LLM 反馈。程序反馈包含层叠缩短、两种 shrinker 与 snap 面分裂等原生策略；不能只用弱的一次输出来证明 LLM 的价值。

网格研究候选仍需通过原生质量、拓扑、采样保真、场景代理和资源门槛。≥90% 层覆盖与近壁代理继续保留为单独的旧 production-layer 标记；未达到该标记但质量安全的网格可以进入研究比较，不能宣布工业合格。

预先冻结“明显改善”为：相对合格程序化首次层网格，≥5 层实际面积提升至少 10 个百分点，实际单元数增加最多 20%，≥1 层覆盖下降不超过 2 个百分点，三个预定义困难诊断区域的 ≥5 层覆盖均下降不超过 2 个百分点。输入基线不合格时单独报告“修复成合格研究候选”，不计算伪造的覆盖增益。

新增原始层数与厚度诊断时，同样要求原始目标层覆盖率、单批加层的设计代理，以及低于半目标厚度的面积不得恶化超过2个百分点。多批切片不使用单一等比公式声称实际首层高度已测准。

各 arm 单元上限相同，实际耗时、阶段次数、单元数和 API 用量分别报告。阶段缓存不能被算作免费算力。只有模型结果优于同预算的程序反馈，才更有力地支持 LLM 决策带来的价值。重复几何不是新的独立样本。

## 蒸馏路线

先建立有效教师，再谈学生：保存可见状态、测量工具回执、合法动作、真实 native 结果、失败原因和版本；不导出模型隐藏推理。离线成功轨迹可作为行为克隆冷启动，但这不等于 OPD。真正 OPD 需要学生在自己的状态/动作分布上采样，再由教师提供指导，并通过同一原生验证器；未来应冻结 tokenizer、teacher checkpoint、student checkpoint 与训练/留出几何划分。

目前实现的是 DeepSeek API 教师与轨迹导出，没有训练学生、执行 OPD 或接通本地推理后端。候选学生可先验证 [Qwen3-VL-8B-Instruct](https://huggingface.co/Qwen/Qwen3-VL-8B-Instruct) 的工具调用和图文证据接口；模型卡为 Apache-2.0。本机 RTX 4060 Laptop 实测显存8GB、系统内存16GB，不能直接容纳仅8B BF16文本权重约16GB再加视觉/KV缓存；量化和较短证据视图需单独测显存与延迟。服务器存在 A800/A40 队列，但可用队列不等于已经部署成功。

OPD 前至少需要：在固定留出车体上，教师重复超过强程序控制；学生采用相同动作与观测接口；学生产生自己的 rollout；教师纠正学生实际访问状态；训练后重新完成同预算 native 对照。现有失败轨迹适合作错误分析，不能全部标成正样本。

## 重现入口

```bash
# 真实源输入审计 + 原生独立 snap / layers 集成；输出目录必须新建
PYTHONPATH=. python scripts/drivaer_prepare.py /absolute/preparation \
  --of-root /absolute/openfoam2412 --source /absolute/drivaer_1.stl
# 冻结相同初始化、相同预算的模型 / 固定程序反馈路线
PYTHONPATH=. python scripts/drivaer_campaign.py /absolute/preparation /absolute/campaign \
  --code /absolute/checkout --key-file /private/deepseek.key
```

campaign 依赖已有 Slurm C64M256G 布局；其他环境需修改启动器，核心 runner 与独立验证器可复用。key 不进入协议或版本库。研究默认每路线最多6个 native 阶段，snap 与 layers 各计一个阶段，阶段计数不能等同旧版完整网格轮次。续跑必须新目录，并声明缓存来源、旧 native 时间与所有共享费用根，禁止重置账本。

输入审计不通过时不启动 paid mesh 搜索。当前保真观察器也可能在有 basic Mesh OK 的网格上拒绝非简单/过度扭曲边界多边形；这类“观测不可用”与被证明的物理表面自交必须分开解释。
