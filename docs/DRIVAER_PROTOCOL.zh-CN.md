# 完整 DrivAer 工程几何对比协议

本实验使用实验输入的 `drivaer_1.stl`，原文件 SHA256 为 `411e6651284a26fc94924106b833fd79febc6deba63922c929dd8acfc99720d2`，大小 142,385,186 字节。753,234 个三角面、376,531 个合并后的顶点组成一个封闭且方向一致的整体；包围盒尺寸约 4.704 × 2.021 × 1.515 米，表面积约 36.10 平方米。所有源部件名称被剥离，完整底盘、车轮、后视镜等三角面都保留。

原坐标通过拓扑检查，但 OpenFOAM v2412 `surfaceCheck -checkSelfIntersection` 报告一处异常。把全部顶点统一平移到包围盒中心后，原生检查通过；统一平移到包围盒角点也通过。两种测试都不改变拓扑或物体形状，坐标逆变换误差在浮点舍入量级。该证据显示检查具有坐标数值敏感性，并不构成所有三角面相交的精确数学证明。实验共同采用居中坐标，保存原输入、转换矩阵和检查记录，不删除或修复车体部件。

两条路线均采用 OpenFOAM v2412、+X 来流、+Z 向上，30 m/s，运动黏度 1.5e-5 m²/s，目标壁函数 y+ 为50，初始请求8层、膨胀率1.2。第一层全高度约1.295毫米，来自平板摩擦关联式，是规划估计而非真实流场 y+。场景为自由外流，不含道路地面、移动地面、旋转车轮；这是当前 Agent 的能力边界，不宣称道路行驶工况已验证。

每条路线最多五次原生体网格尝试，独立保存所有失败。每轮32个 MPI 进程、最多1,800秒原生流程，统一1,200万单元上限。单元上限是资源护栏，并非要求把网格填满。细节加密、表面层数和科学区域变化均记录在 Dict 与决策文件中。

Agent 使用冻结的现有科学核心，在线 DeepSeek 初始规划及反馈；其每个原始案例累计模型费用上限为0.50美元。直接 Codex 路线由独立运行的模型分析原生证据后选择参数，不调用 DeepSeek，也没有自动调参程序。其第一轮方案在 Agent 运行前冻结，后续选择只依据本路线的测量。两条路线共享几何测量、Dict 写入器和原生验收工具，以减小仪器差异；直接路线不是独立商业网格器，也不能把本次单例差异完全归因于基座模型。

基本质量、边界检查、几何保真、单元预算、尾流区域实际分辨率同时决定诊断候选是否可用。不得把质量失败的高层覆盖网格选为成功。层覆盖按实际 `nSurfaceLayers` 和车体多边形面积计算，分别报告至少1层、至少5层及达到本轮要求层数的面积比例。原有至少5层覆盖90%及估计近壁尺度的严格门槛保持不变。

Fluent 的“覆盖率超过80%”来自实验输入的外部参考，没有同一输入的网格、面积定义、层数、第一层高度、单元数和质量日志，因此不进入实测排名，也不能用它直接证明某一软件优劣。尚未进行收敛 CFD、真实 y+、阻力误差或网格独立性验证；达到网格门槛仍不等于工业 RANS 精度通过。

输入几何的公共再分发许可尚未核实。实验保留本地和服务器原始证据，不把实验输入的完整 STL 或体网格直接写入公开发布包。后续展示采用有明确数据来源与限制的真实网格截图、测量表及 Dict。
